# Marketing Intelligence Dashboard: Scarcity, Conversion & Net Loss Insights

## 📊 About the Project
This Power BI project analyzes marketing performance. It provides insights into scarcity, conversion rates, disputes, recoveries, and net loss across regions and categories.

## 📂 Project Files
- [marketing_analysis.csv](./marketing_analysis.csv)

## ⚙️ Steps Performed
1. Cleaned and transformed data in Power BI.
2. Created DAX measures for KPIs (Total Dispute, Total Recovered, Recoup Rate, Scarce Rate, etc.).
3. Built interactive dashboards:
   - **Page 1** → KPI Cards + Filters
   - **Page 2** → Charts and Item Analysis
4. Synced slicers (Region, Category, Date) across pages.

## 🔑 Key Insights
- Identified regions with highest Net Loss.
- Tracked dispute recovery effectiveness using Recoup Rate.
- Highlighted scarce items and their impact on conversion trends.
